# Capstone Project
This project, developed in collaboration with AnaChart, analyzed over 800,000 stock analyst recommendations across 15 years. Using NASDAQ-100 data, we explored analyst ratings, price targets, and stock performance to identify trends, evaluate data quality, and generate actionable market insights.

**About the Project**
This project was completed through Riipen in collaboration with a financial analytics company. The goal was to analyze a large dataset containing 800,000+ stock analyst recommendations spanning approximately 15 years. The analysis focused on NASDAQ-100 companies to explore analyst ratings, price targets, stock performance, and patterns that could support data-driven financial insights.

**Project Highlights**
Analyzed a dataset containing 800,000+ analyst recommendations across approximately 15 years.
Reduced the scope to NASDAQ-100 companies to create a more focused and relevant analysis.
Examined relationships between analyst recommendations, price-target changes, and stock performance.

**How to Navigate the Repo** 
1.  Data Source:The original financial dataset was stored and managed in Google Cloud Platform (GCP).
2.  Data Preparation & Analysis:  Data was cleaned, transformed, and prepared for analysis using Power BI.
3.  Power BI Dashboard: The final processed dataset was connected to Power BI, where interactive dashboards, KPIs, and visualizations were developed.
